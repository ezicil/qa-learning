### Техника попарного тестирования и таблицы решений
Попарное тестирование (pairwise testing) - техника тестирования при которой вместо проверки всех возможных комбинаций значений всех параметров проверяются только комбинации значений каждой пары параметров.
Таблица решений - техника, которая позволяет наглядно представить комбинаторику условий из требований.

##### Пример таблицы решений:

| Условие                                                                   | Тест 1 | Тест 2 | Тест 3 | Тест 4 |
| ------------------------------------------------------------------------- | :----: | :----: | :----: | :----: |
| Валидный логин                                                            |   +    |   +    |   -    |   -    |
| Валидный пароль                                                           |   +    |   -    |   +    |   -    |
| **Действие**                                                              | ------ | ------ | ------ | ------ |
| Пользователь авторизован                                                  |   +    |   -    |   -    |   -    |
| Пользователь не авторизован, появляется сообщение о вводе неверных данных |   -    |   +    |   +    |   +    |

##### Таблица решений для скидки в магазине:


Предположим что незарегистрированные пользователи могут получить скидку только при наличии промокода и только учитывая сам промокод. Регистрация позволяет получить складывающуюся скидку с промокодом на заказ от 5000 рублей не включительно. Сам по себе факт регистрации скидки не дает.
Промокод дает 10%, скидка на заказ от 5000 не включительно тоже 10%.

| Условия                |   Т1   |   Т2   |   Т3   |   Т4   |   Т5   |   Т6   |   Т7   |   Т8   |
| ---------------------- | :----: | :----: | :----: | :----: | :----: | :----: | :----: | :----: |
| Есть промокод          |   +    |   +    |   +    |   +    |   -    |   -    |   -    |   -    |
| Сумма больше 5000      |   +    |   +    |   -    |   -    |   +    |   -    |   +    |   -    |
| Клиент зарегистрирован |   +    |   -    |   -    |   +    |   +    |   +    |   -    |   -    |
| **Результат**          | ------ | ------ | ------ | ------ | ------ | ------ | ------ | ------ |
| Скидка 0%              |        |        |        |        |        |   +    |   +    |   +    |
| Скидка 10%             |        |   +    |   +    |   +    |   +    |        |        |        |
| Скидка 20%             |   +    |        |        |        |        |        |        |        |

#####  Попарное тестирование
	Условия: Три параметра по три значения. Всего - 27 комбинаций. Сократить используя метод попарного тестирования. Будет использован инструмент PICT.
**Параметры:**
1. Шрифт: Calibri, Times New Roman, Arial
2. Форматирование: Жирный, Курсив, Перечеркнутый.
3. Редактор: Word, Notepad, WordPad.
Все параметры указаны на английском языке во избежание конфликта в кодировке.
Итоговая таблица тест-кейсов:

|  №  |      Font       | Format  | Editor  |
| :-: | :-------------: | :-----: | :-----: |
|  1  | Times New Roman | Crossed |  Word   |
|  2  |      Arial      |  Bold   | WordPad |
|  3  |     Calibri     | Italic  |  Word   |
|  4  |      Arial      | Crossed | Notepad |
|  5  |     Calibri     |  Bold   | Notepad |
|  6  | Times New Roman | Italic  | WordPad |
|  7  |      Arial      |  Bold   |  Word   |
|  8  |     Calibri     | Crossed | WordPad |
|  9  | Times New Roman |  Bold   | Notepad |
| 10  |      Arial      | Italic  | Notepad |
Для большей оптимизации тест-кейсов можно убрать 7й случай, так как она является излишней.
