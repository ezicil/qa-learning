### Swagger Petstore тестирование POST /user
Для данного задания было принято (так как в документации нет описания возвращаемых статус кодов), что ожидаемый результат возвращаемого кода ответа:
1. Успешное создание: 201 (200)
2. Запрос с неверными данными: 400/422
3. Запрос без обязательных данных: 400
4. Ошибка сервера 5xx при любых входных данных считается дефектом.

Выводы по тестам:
1. API не валидирует тело запроса: принимает пустое тело, спецсимволы, неверный email, пустые поля.
2. Повторный POST с тем же телом не отклоняется
3. id отправленный в POST не совпадает с id полученным в GET
4. Лишние поля в теле запроса тихо игнорируются
