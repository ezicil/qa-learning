
# 🧪 QA Project: ручное тестирование SauceDemo

Учебный проект по **ручному функциональному тестированию** демо-магазина [saucedemo.com](https://www.saucedemo.com).
Выполнен с нуля как практика.

---

## 📌 О проекте

**Объект тестирования:** SauceDemo — демонстрационный интернет-магазин от Sauce Labs, специально созданный для тренировки тестировщиков.

**Цель:** проверить работоспособность сайта и всех основных пользовательских сценариев, найти дефекты, мешающие пользователю выполнять эти сценарии, и грамотно их задокументировать.

**Тип тестирования:** ручное функциональное тестирование, метод чёрного ящика.

---

## 🎯 Что тестировалось

| Раздел | Что проверялось |
|---|---|
| **Логин** | вход всеми типами аккаунтов, заблокированный пользователь, неверные данные, пустые поля, кириллица |
| **Каталог** | отображение товаров, цены, изображения, страница товара, сортировка (4 варианта), кнопки Add to cart / Remove |
| **Корзина** | добавление и удаление товаров, счётчик, соответствие цен и данных, переходы Continue Shopping / Checkout |
| **Покупка** | форма оформления (валидные данные, пустые поля, каждое поле по отдельности), итоговая сумма и налог, завершение заказа, генерация PDF-чека |
| **Общие тесты** | боковое меню, страница About, Logout, Reset App State, дополнительные демонстрационные страницы |
| **Кроссбраузерность** | сквозной сценарий «вход → корзина → оформление → завершение» в 4 браузерах |
| **Мобильная версия** | основные сценарии в мобильной эмуляции |

**Out of Scope:** тестирование безопасности и нагрузочное тестирование.

---

## 🛠 Подход и окружение

**Техники тест-дизайна:** позитивное и негативное тестирование, классы эквивалентности, граничные значения.

**Окружение:**
- Браузеры (последние версии): Chrome, Firefox, Microsoft Edge, Opera
- Мобильная версия: эмуляция в Chrome DevTools (без реальных устройств)

**Инструменты:**
- Google Docs — тест-план
- Google Sheets — чек-лист и тест-кейсы
- Стандартные средства ОС — скриншоты
