# База данных интернет-магазина

Учебная база данных `shop.db` создана на SQLite и предназначена для хранения информации о пользователях, товарах и заказах. SQL-запросы позволяют получать, фильтровать и анализировать данные магазина.

## Структура базы данных

| Таблица | Описание | Основные поля |
| --- | --- | --- |
| `users` | Пользователи | `id`, `username`, `email`, `created_at` |
| `products` | Товары | `id`, `name`, `price`, `owning` (наличие товара) |
| `orders` | Заказы | `id`, `user_id`, `product_id`, `amount`, `status`, `created_at` |

Таблица `orders` связана с таблицами `users` и `products` через внешние ключи `user_id` и `product_id` соответственно.

## Описание SQL-запросов

### `start_queries.sql`

1. Вывод пользователей и данных их заказов, в которых `amount` больше или равно 10.
2. Подсчёт количества закрытых заказов и суммы значений `amount` по ним с помощью `COUNT` и `SUM`.
3. Вывод имён пользователей, у которых есть заказы со значением `amount` больше 10.

### `continue.sql`

1. Вывод товаров, отсутствующих в наличии (`owning = 'empty'`).
2. Вывод имён пользователей, номеров заказов и названий товаров с сортировкой по имени пользователя и номеру заказа.
3. Поиск пользователей, не имеющих заказов, с помощью `LEFT JOIN`.

## Запуск

Для выполнения запросов необходимо открыть `shop.db` в DB Browser for SQLite или воспользоваться командной строкой SQLite:

```bash
sqlite3 shop.db < start_queries.sql
sqlite3 shop.db < continue.sql
```
